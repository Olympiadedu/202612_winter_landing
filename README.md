# 2026 겨울학기 신입생 모집 랜딩페이지

올림피아드교육의 정적 랜딩페이지입니다. 별도 설치나 빌드 없이 실행합니다.

## 실행

```sh
python -m http.server 4180 --bind 127.0.0.1
```

브라우저에서 http://127.0.0.1:4180/ 접속.

## 배포

GitHub Pages: `main` 브랜치의 루트(`/`)를 배포합니다.

주소: https://sykim4468.github.io/202612_winter_landing/

## 신청 기능 상태

캘린더 및 신청 화면은 미리보기입니다. 실제 응시 일정과 접수 서버는 아직 연결되지 않았으며, 입력 내용은 전송되지 않습니다. 실제 접수 연결 시 `application-preview.js`를 교체합니다.

상단 공식 로고·개인정보 동의·캠퍼스 위치 안내·푸터를 포함합니다. 이미지 경로는 저장소 하위 경로에서도 동작하도록 상대 경로를 사용합니다.
